# **App Name**: Xhunav E-Vote

## Core Features:

- Admin Login: Secure login for admin to access admin dashboard.
- Voter Login: Secure login for voters to access voting platform.
- Admin Dashboard: Dashboard for admin to manage candidates, voters, and elections.
- Candidate Management: Admin to add, edit, and remove candidates.
- Voter Management: Admin to add, edit, and remove voters.
- Election Management: Admin to create, schedule, and manage elections.
- Vote Submission: Voters can vote in active elections with Blockchain enabled and using Post Quantum Cryptography to secure the data.

## Style Guidelines:

- Primary color: Royal Blue (#4169E1) to evoke trust and security.
- Background color: Light Blue (#E6EFFF), a desaturated hue of the primary color.
- Accent color: Orange (#FFA500), an analogous color to create contrast and highlight key actions.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look
- Use simple and professional icons to represent different functions.
- Clean and intuitive layout with clear navigation for admin and voters.
- Subtle animations on button hover and page transitions.
